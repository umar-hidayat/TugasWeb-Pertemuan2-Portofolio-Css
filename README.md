# Tugas Web Pertemuan 2 - Portofolio Personal

Repository ini berisi proyek praktikum mata kuliah Pemrograman Web (Pertemuan 2) berupa landing page dan halaman portofolio personal dasar yang dibangun menggunakan **HTML5** dan **CSS3**.

## 📌 Struktur Proyek

- `index.html` - Struktur utama halaman web (meta tags, semantic HTML tags, navigasi, dan konten utama).
- `style.css` - Berkas styling untuk tampilan visual dan tata letak portofolio.
- `Foto_Setup.webp` - Aset gambar pendukung proyek.

## 🚀 Fitur Utama

- **Semantic HTML**: Menggunakan tag `<header>`, `<nav>`, `<main>`, dan `<section>` untuk struktur kode yang efisien dan standar.
- **Open Graph Metadata**: Dilengkapi dengan properti Open Graph (`og:title`, `og:description`, `og:image`) untuk optimasi *preview* saat tautan dibagikan.
- **Navigasi Internal**: Link navigasi berbasis *anchor link* untuk mempermudah perpindahan antar-bagian halaman.
